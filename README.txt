HOTUZ — статический одностраничный сайт

Файлы:
- index.html — страница
- style.css — адаптивное отображение
- script.js — временное поведение кнопок скачивания
- assets/hotuz-landing.png — утверждённый визуальный макет

Публикация:
Загрузите всё содержимое папки hotuz-site в подключённый GitHub-репозиторий.
Сохраните структуру папок, особенно assets/hotuz-landing.png.

Когда APK будет готов:
1. Положите APK в корень сайта рядом с index.html, например app.apk.
2. В index.html у двух ссылок class="download-hit" замените href="#download" на href="app.apk".
3. Удалите script.js или уберите из него обработчик alert, чтобы браузер начал скачивание файла.

Макет используется как единое изображение, чтобы сохранить утверждённый визуал без отличий. Области обеих кнопок сделаны кликабельными и масштабируются вместе со страницей.
